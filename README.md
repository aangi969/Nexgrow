# Nexgrow

> One Token. A World of Utility.

Nexgrow is a next-generation decentralized utility token ecosystem built on the **BEP-20** standard (BNB Smart Chain), connecting Gaming, Shopping, and Digital Utilities.

## Features
- **Real Digital Utility**: Multi-utility token integration (Play, Shop, Use, Reward).
- **System Utility Vision**: Connected NFT Marketplace, Games, DEX, and Multichain Wallet ecosystem.
- **Institutional Token Architecture**: 50,000,000 NXD total supply with structured annual distribution.
- **Modern Web3 Design System**: Deep emerald and radiant gold palette, interactive hero particle wave dynamics, floating glass capsule navigation, and responsive mobile layout.

## Structure
- `index.html` - Main landing page & ecosystem portal
- `dashboard.html` - Wallet connection & user dashboard
- `disclosure.html` - Risk disclosure & project legal disclaimer
- `assets/style.css` - Official brand design system & stylesheets
- `assets/main.js` - Dynamic interactions, hero green dot wave canvas, mobile drawer & scroll animations
- `assets/` - Official brand assets and logos
